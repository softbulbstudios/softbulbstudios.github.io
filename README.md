# Soft Bulb website

The selected Apple-inspired design, with a homepage offering two equal gateways:
Soft Bulb Studios (games) and Soft Bulb Systems (consulting).

## Open locally

Extract the ZIP, then open `index.html` in a browser.
All styles, fonts, images, and internal pages are included. No installation or build is needed.

## Pages

- Home: `index.html`
- Studios: `games/index.html`
- The Fourth Sense Evolution: `games/fourth-sense/index.html`
- Baseball RPS: `games/baseball-rps/index.html`
- Systems: `consulting/index.html`
- About and contact: `about/index.html`
- Support: `support/index.html`
- Privacy: `privacy/index.html`
- Not found: `404.html`

## Edit or host

Edit the HTML files, `style.css`, and `theme.css` directly.
To host the site, upload this folder's contents to a static website host, keeping the directory structure intact.
The website is a static HTML package; Steam, community, and email links point to their existing destinations.
