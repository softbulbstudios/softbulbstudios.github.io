SOFT BULB - UPLOAD

This is a plain static site. There is nothing to build, compile, or
publish. The files here ARE the website.

Upload the CONTENTS of this folder to the web root for softbulb.io.
The index.html file must sit directly in the web root - not inside a
folder. Keep the assets, images, games, consulting, about, privacy, and
support folders beside index.html, along with 404.html, robots.txt,
sitemap.xml, and the .nojekyll file.

IF YOU USE PORKBUN HOSTING
  Upload via the file manager or FTP. The site is live the moment the
  files finish uploading. Set the custom error page to /404.html.

IF YOU USE GITHUB PAGES
  Commit and push these files to the branch Pages is set to serve.
  Pages redeploys on its own in a minute or two - there is no publish
  button. The .nojekyll file above is required: without it Jekyll
  deletes assets/_vinext_fonts (underscore folders are ignored) and the
  site loses its fonts.

EITHER WAY
  Hard-refresh once (Ctrl+F5) before deciding something did not work.

Delete the previous upload first so the removed files do not linger:
  - assets/*.js          (never referenced; the pages carry no script)
  - .vite/manifest.json  (build metadata, should not be public)
  - .assetsignore
  - file.svg, globe.svg, window.svg
  - images/the-fourth-sense.png, images/data-ai-consulting.png,
    images/soft-bulb-logo-white.png

Do not upload the source project, node_modules, or the dist folder.
